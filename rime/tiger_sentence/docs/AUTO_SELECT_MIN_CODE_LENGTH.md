# 自动选重最低码数

`auto_select_min_code_length` 是组句自动选重的唯一设置，中文名为“自动选重最低码数”。默认 `3`，有效整数范围 `0～128`。

- `0`：禁用自动选重。
- `1～128`：词条的匹配编码至少达到这个长度，才可在组句时省略其选重键。
- 缺失、不可读或非数值：取默认 `3`。负数按 `0`，超过 `128` 按 `128`。

本次合并并移除原“允许单字重码组句”开关。不读取、迁移旧开关；旧 `tiger_sentence_allow_duplicate_single` 的 schema、偏好文件或上下文值不决定新设置。

## 设置方法

在用户目录的 `tiger_sentence.custom.yaml` 中加入或合并：

```yaml
patch:
  tiger_sentence/auto_select_min_code_length: 3
```

将 `3` 改为 `0` 即关闭自动选重，改为 `2` 则允许双码非首选单字自动参与组句。保存后重新部署方案。用户已有 custom 文件时合并到原来的 `patch` 中，不覆盖其它设置。

## 作用边界

门槛按该词条实际匹配的字母编码长度计算，不使用整句话的输入长度，不把数字、分号或引号选重键计入码长。

| 路径 | 默认值 3 下的行为 |
| --- | --- |
| 分段中的双码非首选单字 | 必须显式选重 |
| 分段中的三码或更长非首选单字 | 可自动选重 |
| 码表首选 | 不受此门槛限制 |
| 数字、`;`、`'` 显式选重 | 不受此门槛限制 |
| 整个输入由一个词条完整匹配 | 所有原有名次仍可在候选菜单里手选 |
| 已手动确认或 Tab 锁定的前缀 | 保留已确认的文本和边界 |
| 分段中的非首选多字词 | 保留原规则，仍须显式选重 |

该设置为原有单字自动选重增加码长条件，不扩大多字词的隐式选择权限，也不改变原有一码分段限制、高频最优码过滤、白名单、排序奖励或纠错档位。正码路径和纠错路径使用同一门槛。

## 缓存与学习

修改有效值时，同时废弃普通、锁定后缀和纠错搜索缓存，并清除旧的自动上屏证据及待提交提案；无需重新读取码表或模型。同一有效值继续复用已有缓存。内部无方案参数的解码、诊断调用复用当前设置；不同 schema 各自读取配置或默认值。

原学习模式中的“单字重码”标志由 `auto_select_min_code_length > 0` 派生，不新增按阈值划分的学习命名空间。学习只重排合法路径，不能恢复被新门槛排除的隐式路径。用户显式选择仍可按原学习规则记录。

## 回归验证

`tools/test_auto_select_min_code_length.lua` 在独立临时目录运行实际 Lua 实现，覆盖默认值、`0/1/2/3/4/5/128`、越界、无效值、旧键忽略、首选、完整菜单、显式多位数字/分号/引号、非首选多字词、Unicode 单字、手动锁定、精确可达性、空码候选池、阈值切换、增量/全量及退格一致性。合成 Q8 模型进一步检查纠错格点中的相同资格限制。

已有学习回归中的双码歧义样例显式设置 `2`，继续验证该合法配置下的学习行为；生产默认值仍为 `3`。这些离线检查不等于具体前端的安装或实机输入验收。
