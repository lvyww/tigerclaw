## 4. 本轮压缩到底做了什么

### 共同历史剪枝

按联合单字概率 `.7*P_old + .3*P_new` 排普通字，共22237个，加3个特殊词元共22240；组件缺字在此排序赋零质量。

- 一、二阶全部保留。
- 三阶：历史中的每个字均须位于共同排名前1024。
- 四、五阶：历史中的每个字均须位于共同排名前64。
- 删除整个条件分布，对应log backoff置0；两个组件应用相同、后缀封闭规则。

这是粗粒度 context pruning，**不是相对熵剪枝**。低频字搭配即使很有区分力，也可能整组被删。它在共同词表策略下与线性混合可交换（484项玩具穷举验证），不代表保留了所有重要信息。

先构建640阈值，353,898,569字节；在尚未看候选准确率时按预算扩到1024，499,891,125字节。960无需构建评测。

### 静态融合

工具源于 `/home/yc/tmp/tiger500/mitlm`，隔离生成：
`/home/yc/tmp/shape-mix-rime/interpolate-fixed-v3`。

联合显式n-gram取固定0.7/0.3概率混合；组件缺记录时按组件回退；重算回退权重 `(1-sum P_seen)/(1-sum P_lower_seen)`。权重优化接口禁止调用。

修复隔离副本的 `NgramVector::Sort`：token/history ID改变但位置未变时，原函数提前返回，导致哈希和bounded views没重建。未改上游原目录；断言保留。固定融合29项玩具检查通过。

MITLM输入适配：EOS须位于一阶首行、BOS概率-99、EOS不带BOW。输出给TCS转换前BOS哨兵恢复logp0，避免浪费量化范围；BOS不是预测目标。拒绝NaN/Inf。

**未隔离的差异，下一会话必须记住：**

1. 普通单回退静态模型通常只能近似实时双模型混合，尤其未显式出现的n-gram。
2. 联合词表中某字在组件缺失时，静态工具赋零概率；原实时混合则各自映射UNK。
3. 静态输入原ARPA，原实时对照是两个Q8二进制；最终TCS又用16bit量化。
4. 没做“未剪枝的完整静态融合”对照，不能精确声称各因素分别损失几句。
