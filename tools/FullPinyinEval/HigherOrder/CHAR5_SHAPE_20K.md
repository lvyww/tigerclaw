# 虎整句：Brightmart 纯汉字五阶，旧集＋新集两万句对比

2026-09-22。此次只测准确率，不做延迟对比，不部署，不使用 LLM 或学习。

## 固定口径

- 旧集、新集各 10,000 句；沿用 2026-09-20 size-sweep 的同一编码与目标。
  cases SHA256：`d46d90a24bacf8c43d5c9713eb519062a23441b31e1c5fed45beb031e192372a`。
- 原评测冻结 Rime 解码器 `201eb79264788e16d643315606322215f7b4bf6c`，compact 模式；
  相同码表、字符 rank、补充词表、白名单、词汇先验。三阶为当前默认模型来源
  `trainer_v2/full-kn-m5-v2/sentence-ngram-mobile.bin`。名称 m5 不表示五阶。
- 重新解码两万句，逐条核对首选与目标排名，全部复现历史三阶结果。
  原有 3 条空候选仍计入分母；另有目标不在候选池的样本也未剔除。
- 新模型 `brightmart-char5-20260922/char5-q8.klm`，纯汉字、无注音、5 阶 Q8。
- 保留三阶 Beam 搜索，用新模型重排 Top5 或 Top20。替换公式：
  `新分数 = 原总分 + α × (五阶 lnP − 三阶 lnP)`，两种 LM 都含 BOS/EOS。
  字数奖励、码表 rank 优先规则、主码/词汇/隔离惩罚等其余原分数保留。
  α=1 是五阶评分替换，α=0.5 是三五阶各半；均事先固定，没有用这两万句挑权重。
  **这是五阶重排收益，不是五阶直接参与 Beam 搜索的完整替换测试。**
