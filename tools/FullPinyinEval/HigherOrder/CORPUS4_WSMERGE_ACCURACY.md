# corpus4 wsmerge 冻结形码准确率

2026-09-24，测试重新训练、合并汉字间横向空白的 corpus4 五阶模型。
本次没有追加压缩、插值或部署。模型沿用训练时 `--prune 0 0 1 1 1`。

## 模型与评测口径

- wsmerge：`char5-q8.klm`，SHA256 `4670b65d02d7e261106896da8b2354269b9823b5c1dc861e8a28d8c64eecc83a`。
- 原 corpus4：KenLM Q8，SHA256 `6114583494db90093d7738fe0f268a104dd82d08b0f7b4b80ef95c153787effc`。
- 主线模型：356,492,204 字节 TCSKNM03 Q8，SHA256 `5c46b7c2734886e868c6207a724f4dff2d9c64cb3eba193e7dd44ea9df244361`。
- 使用冻结 Lua 形码解码器和原有 KenLM/TCS 离线适配器，整句完整编码精确匹配；
  同一词表、排名奖励、固定的历史三阶孤立字先验，关闭学习、Qwen 和提前上屏。
  解码器 SHA256 `cf2e735db30b471ad42404b6c722227aba2497c27289644d7bf113ffe0b4d100`。
- 此冻结环境主线 Q8 为 19,929/20,000；当前 C# 环境为 19,930。
  本表内部只比较同一冻结环境，不能与上一轮 Articles 的 C# 分数直接混算。
- wsmerge 三组重新执行；原 corpus4 THUCNews 补测，其他基线复用已有逐句记录。
  比较前检查评测集、解码器、导出器及资源哈希，并逐条核对 ID/输入/目标。

## 验证和限制

- wsmerge 的 Linux 评测副本与用户提供文件完整 SHA256 相同。
- 每次评测前通过 666 项增量/全量、回删及锁前缀检查。
- 每组输入 ID 唯一、所有目标和输入字段逐项匹配、无漏例；统计来自最终候选池。
- 模型 bigram 覆盖和困惑度报告保留在父目录 `VALIDATION.md`；它们与整句准确率是不同指标。
- 冻结评测集与训练语料重合没有全面审计；不能据此宣称独立泛化成绩。
- 本次验证完整模型的离线准确率，尚未转换为当前 C# 主线格式，也没有验收压缩损失、
  内存/延迟、TSF 真实输入或部署。没有更改默认模型与日用安装。
