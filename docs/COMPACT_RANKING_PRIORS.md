# 紧凑整句排序先验

2026-10-09 起，产品默认取消单字主码的 `2.0 × 码长` 加分，C++ Core、C# 参考实现与内置 Rime 保持一致。解码器的显式测试参数仍可用于对照旧分值，正常输入不启用这项奖励。

整段输入一次匹配一个单字时仍有 `5.0` 排序奖励。若该字属于用户设置的前 N 高频字，且不在全码白名单中，则还必须匹配该字的最优码；白名单字及范围外字可以使用任何仍被码表允许的完整输入编码。最优码为最短可用码，同长按源顺序选择。这项奖励不适用于显式选重、词语或句内片段，也不进入置信度质量。

高频字范围、白名单、已有主码过滤、重码规则及模型不因本次调整变化。N=0 时整段单字奖励不再要求最优码。取消主码奖励也作用于句内各分段，减少低频字改用非最优码时的排序损失。

最终排序继续保留两类证据：

- 主码或显式选重的四码及以上单字免除孤立生僻字惩罚；
- 150,032 字节 TCSLEX01 Bloom filter 对原 Top-5 中命中的 2～4 字词提供 `0.10 / 0.12 / 0.14` 的非重叠最大覆盖奖励。

生僻字保护在终点评价，词先验只重排原 Top-5，均不进入 `ConfidenceScore`；无 n-gram 模型时两者关闭。提前上屏阈值、学习奖励与原有置信度计算保持原规则。

虎爪启用 Qwen 时，上述排序属于 Qwen 前的 `BaseScore`；Qwen 仍只接收前五项，融合公式不变。锁定前缀保留四码保护元数据。

词先验共 50,000 条、10 次散列、1,200,000 bit，运行时随 Core 作为嵌入资源加载。来源、转换与许可见 `THIRD_PARTY_NOTICES.md`。
