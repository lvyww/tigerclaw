虎爪输入法（TigerClaw）用户使用说明书

1. 适用范围

本说明书适用于当前发布包目录（含 \1、\1、\1、\1、\1、\1）。

2. 安装与卸载

2.1 安装

  1. 解压发布包到固定目录（建议不要放到临时目录）。
  2. 双击运行 \1。
  3. 按提示授予管理员权限（脚本会自动弹 UAC）。
  4. 安装成功后，不要删除当前目录。配置、码表、日志都在该目录中。

说明：

  • 需要 \1，缺失时安装脚本会自动打开下载页。
  • 安装脚本会将 TSF DLL 复制到 Program Files 并注册，同时写入 Core 自启动项。

2.2 卸载

  1. 双击运行 \1。
  2. 按提示授予管理员权限。
  3. 卸载会清理注册和 Program Files 内的 DLL；原始发布目录默认保留。

5. 自定义选重键

文件：\1

格式： 


<n选> <键1> <键2> ...

示例： 


1选 0x31
2选 0x32 VK_TAB
4选 VK_CAPITAL VK_RSHIFT
10选 0x30

支持写法：

  • 十进制键值（如 \1）
  • 十六进制键值（如 \1）
  • 键名（如 \1、\1）

注意：按键一旦绑定为选重键，在组词状态下会优先按选重逻辑处理。

6.1 码表目录与文件

6.2 基本行格式
